# Как сократить расходы на персонал

Интерактивный справочник по мерам сокращения расходов на персонал по Трудовому кодексу РФ: 12 законных мер — от неполного рабочего времени и простоя до сокращения штата.

## Возможности

- **Подбор меры** — мастер из 4 вопросов (задача, согласие работников, сроки, готовность к формальностям) ранжирует меры: «подходит», «с оговорками», «сложно применить» — с пояснениями.
- **Сравнительная таблица** — все 12 мер с фильтрами: сохранение работников, согласие работника, уведомление госорганов (СФР, служба занятости), профсоюз, предупреждение за 2 месяца.
- **Карточка меры** — полные условия применения и ссылки на статьи ТК РФ.

## Стек

React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui (Radix UI) + lucide-react.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # продакшн-сборка в dist/
```

## Дисклеймер

Справочный материал, не юридическая консультация. Перед применением меры сверьтесь с актуальной редакцией ТК РФ.
